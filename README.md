<div dir="rtl">

| الحالة | المعنى |
| -- | -- |
| **مسموح** | كل السيرفرات مسموحة افتراضيًا، وأوفرواتش قد يتصل بها |
| **محظور** | أوفرواتش لن يتصل بهذا السيرفر |
| **بانتظار إغلاق اللعبة** | لا يمكن تغيير الحظر واللعبة مفتوحة، فأغلق اللعبة والبرنامج مفتوح |

</div>

> [!WARNING]
> **تحذيرات الانقطاع**
> 1. **لا تدخل الطابور مع أشخاص آخرين** إلا إذا كانوا يحظرون نفس السيرفرات
> 2. الحظر يؤثر أيضًا على **الغير مصنّف** و**الألعاب المخصصة**
> 3. إذا فشل الاتصال بسيرفر، اضغط زر **«ارفع كل الحظر»** بسرعة لتتجنب حظر التنافسي

Both files are built from the same code by [GitHub Actions](../../actions); the only difference is the `--features animations` build option. Every version is on the [releases](../../releases) page.

**Two small fixes that aren't in the original (also sent upstream):** results from fetching the IP list and from noticing the game closed are handled right away, even while the window is in the background, instead of waiting for it to be opened; and the "close the game to apply changes" warning no longer shows up every 15 minutes for no reason.

> [!NOTE]
> **Seeing "Windows protected your PC"?** That's Windows SmartScreen, and it shows up for any new file without a download history yet (the original app went through the same thing when it came out). Click **More info**, then **Run anyway**.
>
> All the code is right here and the file is built automatically by GitHub Actions from it; the warning fades as more people run it.

| State | Meaning |
| -- | -- |
| **Allowed** | All servers are allowed by default, and Overwatch may connect to them |
| **Blocked** | Overwatch won't connect to this server |
| **Waiting for the game to close** | Blocks can't change while the game is open, so close the game and keep the app open |

> [!WARNING]
> **Disconnect warnings**
> 1. **Don't queue with other people** unless they block the same servers
> 2. Blocking also affects **unranked** and **custom games**
> 3. If you can't connect to a server, quickly press **"unblock all"** to avoid a competitive ban

```bash
cd dropship
cargo build --release                        # the plain build
cargo build --release --features animations  # the animated build
```

The Thmanyah font is designed and owned by [Thmanyah](https://font.thmanyah.com/); its Medium weight is included in `dropship/assets/fonts/Thmanyah/` with its license file so it's built into the `exe`. If the font file is removed, [IBM Plex Sans Arabic](https://github.com/IBM/plex) (OFL) is used automatically.

Country flags come from [flag-icons](https://github.com/lipis/flag-icons) (MIT), sidebar icons from [lucide](https://lucide.dev) (ISC), and the world map from [Natural Earth](https://www.naturalearthdata.com/) data (public domain).
